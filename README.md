# 天津PM2.5交互可视化

数据可视化实验五。使用 D3.js 在同一网页展示天津监测站地图、日均折线图和月份×小时热力图，分析 PM2.5 高值出现的时间与位置。本页用于同步分工、开发进度和联动状态。
