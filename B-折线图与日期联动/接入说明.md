# 实验五 B 模块接入说明

双击 `index.html` 可离线查看天津样本。站点下拉框和重置按钮用于独立验收。合并时复用 `filters.js`、`timeline.js` 和 `timeline.css` 中 `.pm25-timeline` 的样式，由主页面加载最终站点名单和数据。

## 共用状态

主页面在加载 D3、`filters.js` 和 `timeline.js` 后，只创建一份筛选状态。`startDate` 和 `endDate` 是北京时间日期，起止日均包含。`stationId` 为 `null` 时表示全部选定站点。

```js
const filters = createPm25Filters({
  startDate: '2024-01-05',
  endDate: '2024-01-14',
  stationIds: stations.map(station => station.id),
});

mountPm25Timeline(document.querySelector('#timeline'), {filters, stations, daily});
filters.subscribe(({startDate, endDate, stationId}) => {
  // 地图和热力图在这里使用同一筛选状态更新。
});
```

地图点击站点时调用 `filters.setStation(id)`，点清空时传 `null`。如需由其他视图调整日期，可调用 `filters.setDateRange(startDate, endDate)`。页面重置调用 `filters.reset()`。`subscribe` 注册时立即收到当前状态，返回取消订阅函数。日期拖选结束或点击「应用」时，订阅者会收到更新。

## 数据形状

- `stations` 为 `{id, name}` 的数组，`id` 是字符串。地图可以在相同站点对象上补经纬度。
- `daily` 为 `{date, stationId, validHours, pm25}` 的数组，每站每天至多一条。`pm25` 是该日有效小时观测的均值，单位为 `μg/m³`，缺测用 `null`。折线图只纳入至少 20 个有效小时的记录。
- 无数据的日期不需要补行。日期仍保留在轴上，曲线在对应位置断开。热力图继续使用小时级数据，通过相同日期和站点键筛选。

## 可写入 PDF 的说明

分析目标是识别天津监测站 PM2.5 的日均高值和变化过程，并比较单站与样本站点汇总曲线。折线图上方显示当前站点和日期范围，下方概览支持框选时段，两个日期框用于精确选择。地图选站后更换折线图和热力图的数据，日期变化同步更新其他视图。全站趋势由当日达标站点的日均值等权计算，悬浮时显示参与统计的站点数。只有实际分析中复核通过的日期和数值才写入最终发现。

预览采用 2024-01-05 至 2024-01-14 的 5 个天津站点。逐日核对每个站点的 0 至 23 时记录，共 1200 条，均为原始有效小时观测。正式数据范围和站点名单由全组根据覆盖率确定。原始记录由中国环境监测总站发布。[空气质量历史存档](https://quotsoft.net/air/)
