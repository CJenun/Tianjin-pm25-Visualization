# 实验五 C 模块接入说明

双击 `index.html` 可离线查看已合并的站点地图和日均折线图。地图点位使用与折线图同一份样本，筛选区间为 2024 年 1 月 5—14 日。

- 点击站点可切换折线图，再点同一站恢复全部站点。日期拖选或输入后，地图同步更新颜色和共同有效天数。
- 地图颜色为所选区间内的站点平均日均浓度。一个站点只要在区间内有有效日均值便参加比较。参加比较的站点使用同一组有效日期，无可比值显示灰色。色阶范围在整个样本中固定。
- 接入 A 模块时，在主页面增加热力图容器并加载热力图脚本。在 `main.js` 里复用现有的 `filters`，用 `filters.subscribe(({startDate, endDate, stationId}) => …)` 更新热力图。订阅时会立即收到当前状态。日期为北京时间的自然日，包含两端，`stationId` 为 `null` 表示全部样本站点。热力图用逐小时原始记录计算。

地图轮廓使用 GeoJSON.CN 的天地图来源数据，提取全国文件中编号为 `120000` 的天津市要素。圆点按公开坐标投影，地理位置未随标签偏移而改变。
